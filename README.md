# Roleta da Sorte

Roleta da Sorte é um aplicativo Android simples e divertido que permite criar uma roleta personalizada com suas próprias opções. Adicione as opções que desejar, gire a roleta e veja qual delas será a escolhida!

## Funcionalidades

*   Adicione até 10 opções personalizadas à roleta.
*   Limite de 20 caracteres por opção.
*   A roleta se divide visualmente para cada opção adicionada.
*   Cores aleatórias e vibrantes para as fatias da roleta.
*   Animação de giro suave com resultado claro.
*   Interface limpa e fácil de usar.

## Como Executar o Projeto

Para executar este projeto no Android Studio, siga os seguintes passos:

1.  **Clone o repositório:**
    ```bash
    git clone <URL_DO_REPOSITORIO>
    ```

2.  **Abra no Android Studio:**
    *   Abra o Android Studio.
    *   Clique em "Open an existing Android Studio project".
    *   Navegue até a pasta onde você clonou o repositório e selecione-a.

3.  **Sincronize o Gradle:**
    *   O Android Studio deve sincronizar o projeto com os arquivos Gradle automaticamente. Se não o fizer, clique em "File" > "Sync Project with Gradle Files".

4.  **Execute o Aplicativo:**
    *   Conecte um dispositivo Android ou inicie um emulador.
    *   Clique no botão "Run" (o ícone de play verde) na barra de ferramentas superior.

O aplicativo será compilado e instalado no seu dispositivo/emulador.
